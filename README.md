# LHTRK-Mods (26.3)

Серверні моди на Fabric для сервера Маяк і невеликий серверний ресурс-пак. Зроблено під Minecraft 26.3, Java 21.

## Модулі

### lhtrk-access
Розділяє гравців на Гостей і повноцінних Гравців через `subscribers.json` (також підхоплює старий тег `subscriber`). Гості можуть гуляти Маяком і відкривати двері, але не можуть ламати чи ставити блоки, топтати грядки, бити мобів, підбирати предмети й досвід. Для Гостей діє безсмертя, нескінченна ситість і мирні моби навколо. Якщо Гість вийде за межі `mayak:mayak`, через 5 секунд його поверне на спавн.

Команди:
- `/sub <player>` та `/unsub <player>` видають або забирають доступ Гравця (OP/консоль)
- `/sublist` показує список гравців із доступом (OP/консоль)
- `/subreload` перечитує `subscribers.json` з диска (OP/консоль)
- `/k <target>` примусово вбиває гравця в обхід захисту Гостя (OP/консоль)
- `/stuck` повертає Гостя на спавн Маяка, кулдаун 10 хвилин

### lhtrk-admin
Команди швидкого переміщення між вимірами для OP: `/mayak [target]`, `/overworld [target]` і `/setmayakspawn` (зберігає поточну точку спавну Маяка в `config/lhtrk_mayak.json`).

### lhtrk-afk
Переводить гравця в AFK через 5 хвилин без активності. У табі нік стає сірим, над головою крутяться частинки, а статистика `PLAY_TIME` стає на паузу, щоб не крутилися награні години. Є команда `/afk` для себе і `/afk <target>` для модерації.

### lhtrk-night-skipper
Плавно перемотує ніч до світанку (0 тіків), замість того щоб різко перекидати час. Рахує лише Гравців без AFK у `overworld` та `mayak:mayak`. Поріг сну стартує з 50% і сам підлаштовується від 20% до 90% залежно від того, чи вдалося заснути.

### lhtrk-placeholders
Плейсхолдери для `placeholder-api`: `%lhtrk:playtime_ua%`, `%lhtrk:sub_badge%`, `%lhtrk:role_hover%`, `%lhtrk:world_ua%`, `%lhtrk:advancements%`, `%lhtrk:afk_badge%`, `%lhtrk:online_players%`.

## Ресурс-пак

У папці `resourcepack/` лежать ресурси для клієнта під `pack_format: 97`: логотип Маяка в шапці табу (`\uE001`), іконка `server-icon.png` і українська локалізація для BlazeandCave's Advancements Pack.

## Збірка

```bash
./gradlew build
```

Готові `.jar` файли збираються в `build/mods/`.
